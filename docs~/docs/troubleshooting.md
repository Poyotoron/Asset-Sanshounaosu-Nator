# 困ったときは

## 「参照を検査」が押せない

プロジェクトが Force Text になっていません。ウィンドウ上部の赤い警告から変換してください。詳しくは[事前準備（Force Text）](serialization.md)。

対象を選んでいない場合も押せません。「Project ウィンドウで Prefab（複数可）またはフォルダを選ぶか…」と出ていたら、対象の指定からやり直してください。

## 候補が 1 件も出ない

候補パネルに出ている**探索の内訳**を読むと、理由が分かります。上から順に確認してください。

| 内訳の表示 | 意味 | 対処 |
|---|---|---|
| 手がかり: **なし** | 名前が一切分かっていない | `.unitypackage` の索引を作る、ごみ箱を走査する。名前が判明することがあります |
| プロジェクト内: **無効** | モードを切っている | 探索設定で有効にする |
| `.unitypackage` 索引: **未構築** | 索引がまだ無い | [索引を構築する](search-unitypackage.md) |
| 当該 GUID は索引にありません | その package を登録していない | `.unitypackage` を置いたフォルダを追加して索引を作り直す |
| スコア不足 … | 名前が似ていない | 名前として意味のある一致に満たないものは、あえて出していません |

それでも出ない場合、**元のアセットがどこにも残っていない**可能性があります。その場合はツールでは直せません。配布元から入手し直してください。

## 直したはずなのに直っていない

いくつか原因があります。

### 同じ GUID を、他の Prefab も参照している

まとめて修復で書き換わるのは、**今見ているファイルだけ**です。結果に「同じ GUID は他の Prefab からも参照されています」と出ていた場合、そちらは別途、1 つずつ検査・修復する必要があります。

### 差し替え先が別物だった

再検査後に「同じ Prefab グループの問題が残っています」と警告が出た場合、これが疑われます。Diff プレビューで「解決する override が 1 件もありません」と出ていなかったか確認してください。[バックアップから戻して](backup.md)、候補を選び直すのが確実です。

### 名前一致の `.unitypackage` をインポートしただけだった

名前一致は GUID が違います。**インポートしただけでは繋がりません。** 再検査して、プロジェクト内の候補として選び直してください。詳しくは[.unitypackage から探す](search-unitypackage.md)。

### `.meta` の無いファイルをごみ箱から戻しただけだった

GUID は `.meta` に入っています。本体だけ戻しても新しい GUID が振られるので、参照は繋がりません。[ごみ箱から探す](search-trash.md)を参照してください。

## 間違ったアセットに繋いでしまった

[バックアップとログ](backup.md)の手順で、修復前の `.prefab` を上書きすれば戻せます。**バックアップは修復のたびに自動で取られています。**

Unity 上での見た目が変わってしまっていても、ファイルを戻して再インポートすれば元の状態に戻ります。

## 「対象 Prefab が Prefab Mode で開かれています」

その Prefab を Prefab Mode（Prefab をダブルクリックして開く編集モード）で開いたままにしています。**閉じてから**もう一度実行してください。開いたまま書き換えると、Unity 側のメモリ上の内容で上書きされてしまうため、あえて拒否しています。

## 「検査時の参照位置が現在のファイルと一致しません」

検査したあとに、そのファイルが変更されています（Unity が保存した、別のツールが触った、など）。**もう一度「参照を検査」してから**修復してください。何も書き換えていないので、実害はありません。

## 索引が消えた

`.unitypackage` の索引は `Library/` の中にあります。`Library/` を消したり、プロジェクトを作り直すと消えます。**登録したフォルダの設定は `Assets/` 配下に残っている**ので、「索引を構築 / 更新」を押し直せば作り直せます。

## 検査に時間がかかる / フォルダが増える

- 1 件の検査は数秒で終わります。時間がかかるのは、**まとめて検査**と**索引の構築**です。どちらも進捗が出てキャンセルできます。
- 検査のたびに記録用のフォルダが増えます。修復を含まないものは削除して構いません（[バックアップとログ](backup.md)）。

## Unity のバージョンが違うと言われる

「主な対応環境は Unity 2022.3 です」という警告が出ますが、**検査は続行できます。** 動作を保証している範囲の話です。

## それでも解決しない / 不具合を見つけた

[GitHub の Issues](https://github.com/Poyotoron/Asset-Sanshounaosu-Nator/issues) へ報告してください。次の情報があると調査が早くなります。

- Unity のバージョン
- 何をしたときに起きたか
- 「結果を Markdown でコピー」の出力（**購入アセットの名前が含まれるので、公開してよい範囲か確認してください**）
- Console に出ているエラーメッセージ
