# 更新履歴

変更履歴は GitHub 側で管理しています。二重に持たないため、こちらにはリンクだけを置きます。

[GitHub の CHANGELOG.md を開く](https://github.com/Poyotoron/Asset-Sanshounaosu-Nator/blob/main/CHANGELOG.md)

各バージョンの「既知の制限」も CHANGELOG に書かれています。**このツールで何が直せて何が直せないか**は、そこがいちばん正確です。

ページ下部に表示されている「対応バージョン」が、このサイトが対応しているバージョンです。古いバージョンの説明は残していません。
