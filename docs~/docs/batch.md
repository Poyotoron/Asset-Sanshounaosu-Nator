# まとめて検査する

複数の Prefab やフォルダを一度に検査できます。「アバターのフォルダ全体で、どこが壊れているのか」を把握するための機能です。

!!! warning "まとめてできるのは検査だけです"
    **一括修復はありません。** 書き換えは 1 件ずつ承認します。壊れ方も候補の確度も 1 件ごとに違うため、まとめて書き換える操作は用意していません。

## 使い方

1. Project ウィンドウで **Prefab を複数選択**するか、**フォルダを選択**します。
2. 「選択中を使用」を押します。対象欄に「対象 Prefab: 42 件」のように表示されます。
3. 「参照を検査」を押します。

件数の確認ダイアログが出ます。

> 42 件の Prefab を検査します。完了まで時間がかかる場合があります。

進捗が表示され、**途中でキャンセルできます。** キャンセルした場合は、そこまでに走査した分の結果が表示されます（「キャンセル時点までの結果です」と明示されます）。

## 結果の読み方

先頭に全体のサマリが出ます。

```
検査 42 件 / 問題のある Prefab 5 件 / 問題 137 件
```

その下に、Prefab ごとの折りたたみが並びます。

| 記号 | 意味 |
|---|---|
| `✓` | 問題なし（折りたたまれたまま） |
| `▲` | 問題あり（既定で開きます） |

種別のフィルタは単体検査と同じように効きます。フィルタで全部隠れている場合は「現在のフィルタで表示する問題はありません。」と表示されます。

各項目の中身の読み方は[結果の読み方](results.md)と同じです。「候補を探す」もそのまま使えます。

## 修復は 1 件ずつ

一括結果の中からでも、個別に候補を探して修復できます。修復すると、**その Prefab だけを再検査**して一括結果の該当行が更新されます。他の Prefab の結果は保持されるので、続けて次の項目に取りかかれます。

## 結果を持ち出す

「**一括結果を Markdown でコピー**」で、全体を 1 つの Markdown としてコピーできます。Prefab ごとの見出しと表が並びます。

ログは 1 回の実行につき 1 件、`batch-inspection.md` として書き出されます。

!!! tip "大量に検査するときは"
    検査そのものは非破壊ですが、**Prefab の数だけ時間がかかります。** まずはアバター 1 体分のフォルダなど、範囲を区切って試すことをおすすめします。
